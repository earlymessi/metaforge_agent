| 一级菜单 | 二级菜单 | 三级菜单 | 功能、性能说明 |
|---------|---------|---------|----------------|
| 主控台 | 生产看板 | 生产 KPI 概览 | 展示工单总数、工序总量、待排程数量及 MongoDB 连接状态；页面加载时从服务端拉取统计，用于车间运行态势一眼查看。 |
| 主控台 | 生产看板 | MES 计划执行 | 从已排程计划列表选择计划与基准算法，配置仿真倍速（如 1 分≈1 排程小时）；支持开始执行、暂停、继续、重置。执行中实时刷新仿真时刻与执行甘特，红线标示当前仿真进度。 |
| 主控台 | 生产看板 | 计划甘特预览 | 未开始执行时，按所选计划与算法展示静态甘特预览；开始执行后切换为实时执行甘特，支持设备故障窗口叠加显示。 |
| 主控台 | 生产看板 | 异常重排 | 在 MES 执行运行或暂停状态下，支持插单、设备故障、批量改交期等动态事件触发的重排；重排结果可对比 R0/R1/R2 情景甘特，查看延期与恢复指标。覆盖已有排程时须经确认落库（人机确认）。 |
| 主控台 | 生产看板 | 数字孪生快照（未补齐） | **已实现**：每 2 秒拉取 `/api/digital_twin/snapshot`，表格展示机台/AGV/人员状态与平面坐标；MES 执行中按仿真时刻推算机台 running/idle。**未实现**：三维可视化场景、与看板所选计划强绑定（空闲时多为随机演示或最近计划回放）、AGV/人员运动轨迹动画、与异常重排/物流任务联动。 |
| 主控台 | 数据中心 | 历史工单列表 | 以表格管理 MongoDB 中计划/工单档案：计划名称、工单数、工序数、创建时间、是否已排程；支持刷新、删除。 |
| 主控台 | 数据中心 | 计划导入与跳转 | 将选中计划一键导入智能排程中心编辑；已排程计划可打开分析报表；支持从列表唤起全局智能助手并带入计划上下文。 |
| 主控台 | 数据中心 | 排程快照预览 | 对已保存排程结果提供甘特图缩略图弹窗查看，便于核对历史方案而不重新计算。 |
| 调度排程 | 智能排程 | 算例库模式 | 从内置标准算例库选择 benchmark 文件作为输入，快速验证多种排程算法，适用于算法对比与演示。 |
| 调度排程 | 智能排程 | 自定义/数据库模式 | 在界面维护工单池（优先级、交期、BOM、工序机台与时长）；可绑定数据库计划、编辑计划名称、保存/刷新计划列表，支持 JSON 导入导出。 |
| 调度排程 | 智能排程 | 工艺与 BOM 维护 | 提供工艺路线模板套用与保存、BOM 批量模板、工序高级参数（准备时间/单件工时/数量）；支持静态物料预检及预检明细弹窗，缺料场景可提示风险。 |
| 调度排程 | 智能排程 | 策略与多目标权重 | 选择排程策略模板，配置 makespan、加权交期违约、能耗成本、负载均衡等权重；勾选多求解器（启发式、元启发式、强化学习等）并行对比。 |
| 调度排程 | 智能排程 | 排程计算执行 | 一键「开始排程计算」：支持异步任务（大规模算例防页面超时）、物料约束开关、随机种子；计算完成后结果写入前端状态并引导至分析报表。 |
| 调度排程 | 智能排程 | 自然语言排程（可选） | 在自定义模式下可用中文描述排程意图（如交付优先、对比某两种算法）；系统解析后自动勾选求解器与策略（底层为大语言模型辅助，用户无感知配置）。 |
| 调度排程 | 智能排程 | 排程落库确认 | 「排程并待确认落库」流程：先出排程与交期评估，再生成待确认令牌，用户确认后写入计划库，避免误覆盖已有排程。 |
| 调度排程 | 分析报表 | KPI 概览 | 对本次多算法排程结果按综合评分及完工时间、交期违约、能耗、负载 CV 等指标排序列表；点击行可切换当前分析算法。 |
| 调度排程 | 分析报表 | 甘特图 | 按所选算法绘制工序级甘特图，支持缩放与切换；用于比对不同算法时间安排差异。 |
| 调度排程 | 分析报表 | 收敛曲线 | 展示迭代类算法（如遗传、禁忌搜索）的收敛过程曲线，辅助调参与算法选型。 |
| 调度排程 | 分析报表 | 交期承诺 | 基于当前方案统计交期风险、拖期工单与客户话术要点，服务交付部门评估。 |
| 调度排程 | 分析报表 | 瓶颈分析 | 识别高负荷机台与瓶颈工序，给出负荷分布与改进参考。 |
| 调度排程 | 分析报表 | 结果持久化 | 将选中算法排程结果保存回数据库计划；支持查看历史重排影响评估（延期统计、双甘特对比等）。 |
| 调度排程 | 分析报表 | 物料预检联动 | 若排程时做过物料检查，可在报表页打开预检明细；缺料预警与加工物料调度模块数据一致。 |
| 资源管控 | 能耗管控调度 | 负荷与电价监控 | 展示当前小时、分时电价、各算法能耗成本排名；数据与排程多目标中的能耗项联动。 |
| 资源管控 | 能耗管控调度 | 停机保养窗口 | 维护机台计划停机/保养时段并保存至资源配置；后续排程仿真自动避开该时段，减少计划与现场保养冲突。 |
| 资源管控 | 设备健康管控 | 磨损分析 | 在已有排程方案基础上，按机台统计累计加工时长与磨损红线对比，识别接近阈值的设备。 |
| 资源管控 | 设备健康管控 | 健康配置 | 展示机台功率与磨损阈值配置表，支撑预防性维护决策。 |
| 资源管控 | AGV 物流调度 | 任务生成与批次管理 | **已实现**：按排程甘特提取跨机台工序，调用 `/api/logistics/generate` 执行两阶段全局分配并入库；支持批次号回传、`/api/logistics/batches` 批次列表、`/api/logistics/tasks` 按批次分页查询。 |
| 资源管控 | AGV 物流调度 | 车队调度与监控（部分） | **已实现**：状态机接口 `dispatch/complete`（待派发→执行中→已完成）与前端联动。**未实现**：搬运路径/车间地图可视化、重排后任务自动重算、看板级 KPI（准时率、空驶率）。 |
| 资源管控 | 人员负荷调度 | 人员排班视图 | 结合排程结果展示人员负荷或排班相关信息（依赖当前排程上下文，无排程时提示先排程）。 |
| 资源管控 | 加工物料调度 | 库存与补货 | 维护物料库存、安全库存线，支持补货操作；与 BOM 及排程消耗逻辑一致。 |
| 资源管控 | 加工物料调度 | 库存预测曲线 | 按选定排程方案仿真物料消耗曲线，标注缺料预警；用于齐套与采购参考。 |
| 全局功能 | 车间智能助手 | 对话与计划绑定 | 侧栏抽屉/Global 按钮唤起；可选择、新建、解绑生产计划，会话内续聊。用户用中文描述排程、重排、齐套、交期、方案对比、计划库操作等需求。 |
| 全局功能 | 车间智能助手 | 执行过程展示 | 流式展示意图识别、执行计划与各 Tool 步骤状态；结果以卡片形式呈现（对比表、甘特入口、交期风险、齐套报告等），可跳转排程中心或分析报表。 |
| 全局功能 | 车间智能助手 | 落库与人机确认 | 助手发起写库前弹出确认框，用户确认后完成计划更新；与会话绑定，服务重启后仍可续确认（MongoDB 会话模式）。 |
| 全局功能 | 系统运行 | 数据库连接状态 | 侧栏与顶栏显示 MongoDB 在线状态；会话与计划、执行态、HITL 令牌持久化至数据库，默认会话有效期约 1 小时可配置。 |
| 全局功能 | 系统运行 | 多算法引擎 | 后端集成 SPT、禁忌搜索、遗传算法、模拟退火、蚁群、Q 学习、DQN、PPO、神经进化等求解器；排程核心为确定性计算，保证同输入可复现。 |
| 全局功能 | 系统运行 | 异常事件 API | 除界面外，生产看板重排与助手共用同一套事件重排服务（插单、故障、改交期、停机、到料延迟等 8 类），保证 MES 与对话入口结果一致。 |

## 技术说明（非菜单项，附录）

下列能力为用户可见功能的**实现支撑**，不单独作为软件菜单列出：

- **自然语言理解**：智能排程可选语句、车间助手对话，由服务端编排器完成意图识别与工具链调度。  
- **多业务场景分发**：排程、异常重排、齐套、交期评估、方案对比、计划库管理等由不同业务逻辑模块处理，对用户统一呈现为助手或表单操作。  
- **规则回退**：网络或模型不可用时，关键词与规则仍可完成基础路由与排程参数解析，保障离线演示与测试。
