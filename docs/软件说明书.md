## 1 引言

### 1.1 编写目的

本说明书介绍本软件的功能组成、运行环境、安装启动方法及界面操作步骤，帮助使用者正确安装、启动并操作各功能模块。

### 1.2 软件概述

本系统面向离散制造车间的**智能排程与制造执行（MES）**场景，以作业车间调度（JSSP）为计算内核，集成多种启发式、元启发式与强化学习求解器；通过 Web 界面完成计划管理、排程计算、执行仿真、异常重排、资源协同与智能助手对话。数据持久化采用 MongoDB，前后端统一由本机 **8008** 端口提供服务。

### 1.3 术语说明

| 术语 | 说明 |
|------|------|
| APS | 高级计划与排程（Advanced Planning and Scheduling） |
| MES | 制造执行系统仿真（本系统中指计划执行与甘特推进） |
| 甘特图 | 以时间轴展示工序在机台上的安排 |
| 人机确认 | 写库前弹出确认框，用户确认后才写入数据库 |
| 算例库 | 内置标准 benchmark 数据集，用于算法验证 |
| 智能助手 | 自然语言交互入口，可驱动排程、重排、齐套、交期评估等业务 |

### 1.4 适用范围

- 部署方式：**Windows 本机一体化部署**（应用服务、数据库、浏览器客户端在同一台计算机）。
- 系统形态：**B/S 架构 Web 应用**，通过浏览器访问，无需安装独立客户端。

## 3 安装与启动

### 3.1 安装前提

使用前请确认已安装：Python 3.8 及以上（建议 3.12）、MongoDB（Windows 服务）、Node.js（用于前端构建）、Chrome 或 Edge 浏览器。

### 3.2 安装步骤

在项目根目录（含 `pyproject.toml`）依次执行：

```powershell
# 1. 启动 MongoDB
Start-Service MongoDB

# 2. 安装 Python 依赖
pip install -e .

# 3. 构建前端（首次或前端有变更时）
cd .\frontend
npm install
npm run build
cd ..

# 4. 启动后端
cd .\tests
python .\main.py
```

### 3.3 启动成功判定

控制台应出现：

- `MetaForge Backend (FastAPI+Motor) running on http://127.0.0.1:8008`
- `MongoDB 已连接`

浏览器访问 `http://127.0.0.1:8008/new-ui/`，应显示系统主界面；侧栏底部显示数据库已连接，顶栏显示 **MongoDB Online**。

### 3.4 启动验证

| 验证项 | 操作方法 | 正常表现 |
|--------|----------|----------|
| 后端服务 | 浏览器访问 `http://127.0.0.1:8008/api/benchmarks` | 返回 JSON 算例列表 |
| 数据库 | 打开「数据中心」页面 | 计划列表可加载，无报错 |
| 前端页面 | 访问 `http://127.0.0.1:8008/new-ui/dashboard` | 生产看板正常显示 |

### 3.5 停止服务

在运行 `python main.py` 的终端按 `Ctrl+C` 停止后端。MongoDB 服务可保持运行。

## 4 系统结构与功能组成

### 4.1 总体架构

系统采用 **B/S 三层结构**：

- **表示层**：Vue3 + Element Plus 单页应用，由 FastAPI 托管静态资源。
- **业务层**：FastAPI 提供 REST API；编排器负责智能助手路由；六大业务模块调用后端服务完成排程、重排、齐套等。
- **数据层**：MongoDB 存储计划、排程结果、会话、物流任务、物料库存等。

### 4.2 功能模块一览

| 一级模块 | 二级菜单 | 主要功能 |

| 调度排程 | 智能排程 | 算例库/自定义排程、工艺 BOM、策略权重、排程计算、落库确认 |
| 调度排程 | 分析报表 | KPI、甘特、收敛曲线、交期承诺、瓶颈分析、结果保存 |
| 资源管控 | 能耗管控调度 | 负荷电价监控、停机保养窗口 |
| 资源管控 | 设备健康管控 | 磨损分析、健康配置 |
| 资源管控 | AGV 物流调度 | 任务生成、批次管理、派发/完成状态机 |

### 4.4 排程求解器

系统内置多种求解器，包括但不限于：SPT、禁忌搜索（TS）、遗传算法（GA）、模拟退火（SA）、蚁群（ACO）、Q 学习、DQN、PPO、神经进化等。同输入、同随机种子条件下，确定性算法结果可复现。

## 5 界面与操作说明

以下按系统菜单组织，每节说明进入方式、操作步骤与正常表现。

### 5.1 生产看板

**进入**：侧栏「主控台 → 生产看板」，或访问 `/new-ui/dashboard`。

#### 5.1.1 生产 KPI 概览

1. 打开生产看板页面。
2. 查看页面顶部或统计区域。

**正常表现**：显示工单总数、工序总量、待排程数量；数据库连接状态为在线。

#### 5.1.2 MES 计划执行

1. 在计划下拉框中选择一个**已排程**的计划。
2. 选择基准算法。
3. 设置仿真倍速，点击「开始执行」。
4. 观察甘特图与仿真时刻推进；可依次使用「暂停」「继续」「重置」。

**正常表现**：

- 执行中甘特图随仿真时刻刷新，当前进度有明确标识。
- 暂停后时刻停止推进；继续后恢复；重置后回到初始状态。

#### 5.1.3 计划甘特预览

1. 选择计划与算法，在未开始执行时查看甘特预览。
2. 开始执行后观察甘特由静态切换为实时。

**正常表现**：甘特图正常渲染，可辨识各工序在机台上的时间条。

#### 5.1.4 异常重排

1. 在 MES 执行运行或暂停状态下，触发重排（设备故障、插单、批量改交期等）。
2. 查看 R0/R1/R2 情景对比与延期指标。
3. 若涉及覆盖已有排程，按提示完成人机确认。

**正常表现**：返回重排结果与对比视图；确认落库后数据写入计划库。

---

### 5.2 数据中心

**进入**：侧栏「主控台 → 数据中心」，或访问 `/new-ui/database`。

#### 5.2.1 历史工单列表

1. 打开数据中心，查看计划列表。
2. 点击「刷新」。
3. 选择一条记录执行「删除」。

**正常表现**：列表展示计划名称、工单数、工序数、创建时间、是否已排程；刷新后数据更新；删除后记录消失。

#### 5.2.2 计划导入与跳转

1. 选中一条计划，点击导入智能排程或打开分析报表。
2. 可从列表唤起智能助手并带入计划上下文。

**正常表现**：页面跳转至对应模块，上下文计划正确绑定。

#### 5.2.3 排程快照预览

1. 对已排程计划，打开甘特缩略图预览弹窗。

**正常表现**：弹窗内显示该计划排程甘特缩略图，无需重新计算。

---

### 5.3 智能排程

**进入**：侧栏「调度排程 → 智能排程」，或访问 `/new-ui/aps`。

#### 5.3.1 算例库模式排程

1. 切换至算例库模式。
2. 从列表选择 benchmark 算例（如 ft06）。
3. 勾选一种或多种求解器，点击「开始排程计算」。
4. 计算完成后进入分析报表查看结果。

**正常表现**：算例加载成功；计算完成无报错；报表中可见各算法 KPI 与甘特。

#### 5.3.2 自定义/数据库模式

1. 切换至自定义或数据库模式。
2. 新建或编辑工单（优先级、交期、工序、机台、工时等）。
3. 保存计划；可使用 JSON 导入/导出。

**正常表现**：表单可编辑保存；导入导出文件格式正确；非法 JSON 有错误提示。

#### 5.3.3 工艺与 BOM、物料预检

1. 套用工艺路线模板或编辑 BOM。
2. 执行静态物料预检，打开预检明细。

**正常表现**：模板套用成功；缺料场景有预警提示；明细与 BOM 一致。

#### 5.3.4 策略与多目标权重

1. 选择策略模板，调整 makespan、交期违约、能耗、负载均衡等权重。
2. 勾选多求解器并行对比。

**正常表现**：权重与求解器选项可联动；提交后进入计算流程。

#### 5.3.5 排程落库确认

1. 完成排程后，选择「排程并待确认落库」。
2. 在确认弹窗中查看预览，点击确认写入。

**正常表现**：弹出确认框；确认后计划库中排程结果更新；取消则不写入。

#### 5.3.6 自然语言排程

1. 在自定义模式下输入中文排程意图（如「交付优先，对比禁忌搜索和遗传算法」）。
2. 观察系统自动勾选求解器与策略。

**正常表现**：解析后参数自动填充；未配置大模型时回退到规则解析并给出提示。

---

### 5.4 分析报表

**进入**：排程计算完成后自动引导，或侧栏「调度排程 → 分析报表」，或访问 `/new-ui/reports`。

1. 在 KPI 概览中点击不同算法行，切换当前分析对象。
2. 查看甘特图、收敛曲线、交期承诺、瓶颈分析。
3. 将选中算法结果保存回数据库计划。

**正常表现**：各页签数据与所选算法一致；甘特可缩放切换；保存后数据中心显示已排程。

---

### 5.5 资源管控

#### 5.5.1 能耗管控调度（`/new-ui/energy`）

1. 查看当前小时、分时电价与各算法能耗成本排名。
2. 维护机台停机/保养窗口并保存。

**正常表现**：能耗数据与排程结果联动；保存后资源配置更新，后续仿真可避开停机时段。

#### 5.5.2 设备健康管控（`/new-ui/health`）

1. 在已有排程方案下查看磨损分析。
2. 查看/编辑机台功率与磨损阈值配置。

**正常表现**：接近阈值的设备有标识；配置保存成功。

#### 5.5.3 AGV 物流调度（`/new-ui/logistics`）

1. 基于已排程甘特生成物流任务。
2. 查看批次列表与任务分页。
3. 对任务执行「派发」「完成」操作。

**正常表现**：生成任务并入库；状态由待派发→执行中→已完成流转。

#### 5.5.4 人员负荷调度（`/new-ui/staffing`）

1. 在有排程上下文时打开页面，查看人员负荷/排班信息。

**正常表现**：有数据时正常展示；无排程时提示先完成排程。

#### 5.5.5 加工物料调度（`/new-ui/materials`）

1. 维护物料库存与安全库存，执行补货。
2. 基于排程方案查看库存消耗预测曲线。

**正常表现**：补货后库存更新；预测曲线标注缺料预警，与预检数据一致。

---

### 5.6 车间智能助手

**进入**：顶栏智能助手按钮（全局抽屉），或访问 `/new-ui/assistant`。

#### 5.6.1 对话与计划绑定

1. 打开助手，选择或新建生产计划并绑定。
2. 输入中文指令，例如：
   - 「用禁忌搜索排一下当前计划」
   - 「3 号机故障 4 小时，帮我重排」
   - 「看一下交期风险」
   - 「对比 SPT 和 GA」

**正常表现**：流式返回执行过程；最终给出可读摘要或结果卡片；可跳转相关页面。

#### 5.6.2 人机确认落库

1. 通过助手触发写库操作。
2. 在确认弹窗中批准或拒绝。

**正常表现**：批准则数据落库；拒绝则不写入。服务重启后，同一会话内待确认项可继续确认。

## 7 典型业务流程

按下列顺序操作，可完成从排程到执行仿真的完整业务闭环：

| 步骤 | 模块 | 操作 | 正常表现 |
|------|------|------|----------|
| 1 | 启动 | 按第 3 章启动系统 | 浏览器可访问，数据库显示在线 |

| 3 | 智能排程 | 算例库选择 ft06，勾选 SPT 并排程 | 计算成功，进入分析报表 |

## 9 常见问题

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| 页面仅显示 JSON 或无样式 | 前端未构建 | 执行 `cd frontend && npm run build` |
| 数据库离线 | MongoDB 未启动 | 执行 `Start-Service MongoDB` |
| 排程耗时过长 | 算例过大或勾选算法过多 | 先用小算例 ft06 验证 |
| 助手回复较简单 | 未配置大模型密钥 | 在项目根目录 `.env` 中配置 `ZHIPU_API_KEY`；未配置时使用规则解析 |
| 端口无法访问 | 8008 端口被占用 | 关闭占用进程，或修改环境变量 `METAFORGE_PORT` |
| 落库失败 | 未确认或令牌过期 | 重新发起排程并完成确认 |
